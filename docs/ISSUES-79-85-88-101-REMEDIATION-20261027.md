# BCG.LK — tracked remediation for issues #79, #85, #88 and #101

Date: 2026-10-27. This is a release hold, not an acceptance certificate.

## Verified source work

- Latest `main` already includes the CMS editor's audited submit/approve/publish,
  proposed published edits, recoverable Delete / Restore, and deny-direct-publish
  Firestore rules **in source**. Deployed Firebase rules and real admin behavior
  remain unverified. The 26 October issue descriptions are partly superseded.
- This branch replaces the first-1,000-only `cmsTrash` verification query with
  bounded, ordered pages. It validates same-kind cursors, checks every returned
  archive ID and fails closed above 8,000 archived records rather than hiding
  deletions. This is not general CMS pagination.
- This branch adds `scripts/check-firestore-index-safety.mjs`, which compares the
  owner-obtained live Firestore index export with the proposed managed index file
  **before** any index deployment. Missing existing indexes and field overrides
  block the preflight. This tool does not connect to Firebase.
